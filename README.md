# Düşen Harfler · Falling Letters

Harfleri yakala, kelime kur!

Yukarıdan harfler düşer; dokunarak sekiz yerlik tepsine al. Tepsideki harflerden kelime seçip gönder; kullanılan harfler boşalır. Kaçan harfler puan düşürür. Hedef sayıda kelime kur.

100.000 bölüm; her bölüm üretilir ve kurallara göre doğrulanır. Kelime Oyunları merkez uygulamasının oyunu; ortak motor: [kelime-motoru](https://github.com/taktemurr-ops/kelime-motoru).
